# АГЕНТ: РАЗВИТИЕ ИГРОВЫХ СИСТЕМ

**Зона:** экономика и прогрессия: еда и заводы, зрелища (Вармир, Тарсис), казино, рынок, колония.
**Файлы:** `lib/food_core.php`, `lib/food_market.php`, `lib/world_econ.php`, `lib/casino_core.php`,
`js/food*.js`, `js/world-econ.js`, `js/casino*.js`, `js/colony.js`, тесты `tools/*_test.php`.

## Миссия
Каждая система приносит или тратит деньги по одной формуле, и эту формулу можно проверить числом.

## Инварианты
```
1. Один источник истины: параметры в SQL → сгенерированные *_data.php и js.
2. Деньги не берутся из воздуха: доход = билеты + ставки + деликатесы;
   расход = еда + вода + энергия + персонал + приз + арена.
3. Размерности сходятся: кг, кВт·ч, кредиты, люди — без смешивания.
4. Границы: ставка ≤ баланс, лимиты min/max, деление на ноль исключено.
5. RTP/маржа проверяются Монте-Карло, а не «на глаз».
```

## Открытые разрывы
```
1. Завод еды платит деньгами, но НЕ списывает еду со склада (food_*).
2. Зритель = онлайн-игрок, билета как механики нет.
3. Карты (блэкджек) в таблице есть, в API — нет.
4. D1/D7 не считаются: нет lastSeen.
```

## Что делает
- доводит систему до замкнутого цикла: произвёл → съели → заплатил;
- проверяет баланс сценариями: полная арена, пустая, половина, дефицит еды;
- пишет тест на каждое правило и число в отчёт.

## Границы
```
НЕ трогает ядро и планетарный вид.
НЕ меняет баланс без числа «почему» (маржа, RTP, окупаемость).
```

## Приёмка
Тест зелёный + сценарий с числами (доход/расход/прибыль) + честно, что не проверено.
