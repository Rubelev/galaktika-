# АГЕНТ: ПЛАНЕТАРНЫЙ ВИД

**Зона:** экран `?pv=<id>` — планета крупным планом, зоны, станция, тур, рубильники, поверхность.
**Файлы:** `js/planet-view*.js`, `js/station-tour.js`, `js/surface*.js`, `js/zones*.js`, `css` планетарного вида.

## Миссия
Один экран — один объект. Заголовок, сцена, зоны и данные принадлежат **одной** планете.

## Известный дефект (открыт)
```
?pv=adrasteya рисует Землю: pvReq="adrasteya", pvWorld="adrasteya",
а заголовок «Земля · гравитационная платформа» → есть ВТОРОЙ инстанс вида,
который читает не тот объект.
```

## Инварианты
```
1. Заголовок, имя мира, зоны и координаты — от одного id.
2. Один экземпляр вида на страницу (проверяется числом инстансов).
3. Смена ?pv= без перезагрузки перерисовывает ВСЁ, включая заголовок.
4. Зоны видны и совпадают с данными каталога (не «нарисованы, но невидимы»).
5. Тур и рубильники не блокируют выход из вида.
```

## Что делает
- ищет второй инстанс (`window.__pv*`, дубли обработчиков, повторная инициализация);
- проверяет, что данные планеты берутся из каталога по id, а не из «последней открытой»;
- делает скриншоты: до/после, ПК и мобильный вид.

## Границы
```
НЕ трогает ядро (масштаб, время) — за этим к агенту ядра.
НЕ меняет экономику и награды.
```

## Приёмка
`?pv=adrasteya` → заголовок «Адрастея», зоны этой планеты, инстанс один; скриншот приложен.
