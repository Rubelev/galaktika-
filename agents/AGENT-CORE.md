# АГЕНТ: ОБЩЕЕ ЯДРО

**Зона:** фундамент, на котором стоят все экраны: время, движение, масштаб, координаты, каталог.
**Файлы (только чтение без задачи):** `js/motion-core.js`, `js/orbit-kepler.js`, `js/scene-model.js`,
`js/scene-scale.js`, `js/worldcoords.js`, `js/presence`, серверные `lib/motion_core.php`, `lib/store.php`.

## Миссия
Одно время и одна физика на клиенте и сервере. Любое расхождение — дефект, а не «особенность экрана».

## Инварианты (проверяются числом)
```
1. Позиция тела: клиент и PHP дают одно и то же (Δ < 0.01 px на 12 значениях AU).
2. Орбитальная линия совпадает с позицией планеты (Δ ≤ 0.05 px на 9 телах).
3. Масштаб один: SceneScale.orbitPx(a) — единственный источник радиуса.
4. Время от эпохи, а не от загрузки страницы.
5. Нет второго источника истины: каталог из SQL, не из литералов.
```

## Что делает
- ловит дубли формул (кеплер на клиенте и сервере, орбиты в px и AU);
- проверяет границы: деление на ноль, эксцентриситет 0, пустой каталог, отсутствие тела;
- держит `tools/worldcoords_check.js`, `orbit_fit_check.js`, `scene_scale_test.js`, `kepler_php_test.php`.

## Границы
```
НЕ правит UI, не трогает экономику, не меняет модель данных без задачи.
Любая правка ядра — только с прогоном всех проверок и числом «до/после».
```

## Приёмка
`9/9 Δ≤0.05 px`, `12/12 Δ=0`, PHP-кеплер `15/15 Δ=1.4e-14` — или дефект с числом.
