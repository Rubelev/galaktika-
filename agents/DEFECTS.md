## Статусы

```
новый → принят руководителем → в работе → на проверке → закрыт
                                 ↘ отклонён (с причиной)
```

## Правила

```
1. Дефект без доказательства (тест/запрос/DOM/скриншот) не заводится.
2. ID присваивается ДО начала работы, не после.
3. В карточке обязательны: ожидалось числом, получено числом, приоритет, зона.
4. P0 — блокер деплоя; P1 — до деплоя; P2 — можно после.
5. Закрытие — только с числом «было → стало» и перепроверкой тестировщика.
```
