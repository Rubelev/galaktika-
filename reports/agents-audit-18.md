## Причина (цитата кода)

`catalog-bridge.js` (посредник) вызывает `SceneModel.orbitPosition(b, timeMs)`, а тот проверяет **поля с префиксом `orbit_`**:

```js
// scene-model.js, orbitPosition():
if (global.OrbitKepler && body.orbit_e !== undefined && body.orbit_e !== null) {
    // ...считаем по настоящей орбите
}
// иначе — круговое приближение, которое возвращает 0,0
```

Каталог же отдаёт поля **без префикса**: `{id:'earth', a:1, e:0.0167, i:0, om:-11.26, w:114.21, m0:358.62, P:365.25}` (проверено: `CATALOG.bodies.find(b => b.id === 'earth')`).

Отсюда: **у всех тел `orbit_e === undefined`** → ветка Кеплера не выполняется → `orbitPosition` возвращает `(0,0)`; `solar.js` не создаёт `.planet`/`.moon` (их 0), а в `SceneModel.frame` массив тел приходит не массивом → исключение. Линии орбит при этом рисуются отдельно (`CatalogBridge.path` → `OrbitKepler.path`), поэтому на экране видны кольца, пояс, Солнце и портал — но **ни одной планеты, луны или корабля**.

## Вердикт

- **43 тела каталога: соответствуют 0 из 43** — ни одно не отрисовано; координаты моста `(0,0)`; `SceneModel.frame` падает.
- **8 агентов: 0 из 8** — `.ship-marker` = 0.
- Единственное, что работает: таблица классов кораблей (vmax 0,30/0,25/0,15/0,10) и отрисовка 9 линий орбит.
- **Причина по коду:** `scene-model.js::orbitPosition` проверяет `body.orbit_e`, а каталог отдаёт `body.e` (то же для `orbit_a`, `orbit_i`, `orbit_om`, `orbit_w`, `orbit_M0`) → ветка Кеплера не выполняется, возвращается `(0,0)`.

## Что не проверено и почему

1. **Движение за 5 кадров (шаг 60 с), скорость px/45с, доля c, отклонение от орбиты ≤6 px** — не измерялись, потому что объектов в сцене нет (мерить нечего).
2. **Лимиты классов** — проверены только по данным каталога (`CATALOG.ships`), не по фактическому движению.
3. **Кольца Сатурна** — элемента Сатурна нет, «сжатие в линию» проверить нельзя.
4. **«Квадратное» Солнце** — PIL-замер перекрыт поясом (bbox свечения 69×152 на tilt=0), достоверно не измерено.
5. **Луны: расстояние до родителя 8–120 px** — лун нет в DOM.
6. **Серверные данные игроков не трогались**, деплой не выполнялся.
