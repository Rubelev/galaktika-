## H-01 (P0): клиентский `force` обходил кулдаун

**Было.** `api.php` (case `world_tick`) читал `$input['force']` и при `force = true` пропускал проверку `($now - $last) < 3600`. Панель (`js/world-event-panel.js:81`) отправляла `{force: true}` на каждый клик. Итог: любой игрок мог крутить событие без ограничения — доход с клика не ограничен.

**Стало.**

| Слой | Что сделано |
|---|---|
| `lib/world_econ.php` | новая `world_tick_gate($lastTick, $now, $isAdmin, $force)` + `WE_TICK_COOLDOWN = 3600`. Частоту решает сервер: `force` учитывается **только** при `$isAdmin === true`; иначе — 429 с `wait_sec` |
| `api.php` (`world_tick`) | вызов гейта, `json_out(429, {error, wait_sec, cooldown})`; в успешном ответе появились `forced` и `wait_sec` |
| `js/world-event-panel.js` | `force` больше **не отправляется** (`api('world_tick', {})`); при 429 показывается «ещё рано — через N мин» |

**Поведение (тест `tools/world_tick_test.php`, 9/9):**

## H-02: арены при 25 % заполнения

**Было.** `fill = 0.25 + 0.05 × online`, при нулевом онлайне это 25 % — и 5 из 6 арен были в минусе (Сфера −287 820 при 30 %).

**Почему нельзя было обойтись только «снизить upkeep».** Маржа линейна по заполнению:
`маржа(f) = (f·A − F) / (f·B)`, где `A = N(R−C)`, `B = N·R`, `R` — выручка на гостя, `C` — расход на гостя, `F` — постоянные.
Отсюда `маржа(100 %) − маржа(25 %) = 3F/B`: чтобы при 25 % было ≥ 10 %, а при 100 % ≤ 60 %, нужно `F/B ≤ 0.167` и `0.55 ≤ C/R ≤ 0.70`. У «Купола» и «Сферы» отношение `C/R` было 0.19–0.14 (билет 95/140 против 29,8/31 затрат) — при любой разумной `F` они давали либо минус при 25 %, либо > 60 % при 100 %. Поэтому пришлось тронуть и выручку на гостя: ставки перестали быть «печатным станком» (маржа тотализатора 8–11 % → 3–6,5 %), билет выровнен по лестнице 45→70.

**Побочные следствия, которые надо знать:**
1. Персонал арен сокращён примерно вдвое (30→10 … 320→119) — иначе постоянные затраты не дают 25 %-заполнению выйти в плюс.
2. Маржа тотализатора снижена до 3–6,5 %: ставки перестали быть основным источником (у Сферы было 71,5 кр на гостя из 223).
3. Билеты теперь дают 58–77 % выручки, деликатесы 12,7–14,9 % — прежние тесты («деликатесы > 5 %», «билеты > 40 %») проходят.
4. Безубыточность ~17 % вместимости у всех арен: пустая арена по-прежнему в убытке (−F), половина зала прибыльна.
5. Правка внесена и в `db/galaktika.db → world_event_econ` (6 строк), чтобы регенерация `world_econ_data.php` не откатила баланс.
