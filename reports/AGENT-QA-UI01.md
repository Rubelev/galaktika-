живой `wait_sec = 84882` → `fmtWait` = **24 ч** (это 84882/3600 с округлением вверх, а не литерал);
в стаб-скриншоте `after6` сервер отдал 8 ч → показано **8 ч**. После 429 клиент перезапрашивает статус.

## 8. Наблюдения (не блокируют)

1. **Живой сайт пока со старыми файлами:** `js/encyclopedia.js 859341a7`, `js/solar.js 836b4f3a`
   (это site-копии), тогда как новые — `src` `a952b0f9` / `d8f5568f`. Деплой (`deploy.ps1:104-115`
   `src → site`) обновит оба; без деплоя изменений на сервере нет.
2. **Старая site-копия выключала кнопку «Бросок» при 0 попыток** (`disabled`), в новом `src` этого нет:
   после деплоя кнопка при 0 остаётся активной → клик даст 429 и баннер с wait_sec. На критерий не влияет,
   но это UX-регресс относительно текущего live; стоит вернуть `disabled` (1 строка).
3. `trophyStyles()` вызывается в `open()` (`:106`) — на старом site-копии вызова нет; стили коллекции
   появляются только с новой версией. Скриншоты стилизованы → сняты с нового `src`.
4. В stub-снимках в шапке нет «следующий через…» — стаб возвращал `rolls.wait_sec = 0`; в `real-init`
   с живым API строка есть. Это не баг UI.
