## Итог

- **Прямой адрес `/?pv=<id>` — стабилен на 32 из 32 тел** (9 планет + 23 луны): поверхность открывается, `pv-mode` включён, карта скрыта, ошибок и баннеров нет.
- **Спуск из глобуса — 32 из 32**: новая вкладка с `?pv=<id>`, в ней поверхность (проверено для 8 тел), исходная карта не теряется.
- **Полный цикл (вход → поверхность → «К глобусу» → повторный спуск)** — корректен на **0 из 8**: возврат оставляет PV-слой видимым и не открывает глобус, повторный спуск требует ручного открытия глобуса.
- **Варианты tilt/zoom/canvas — 24 из 24** (8 тел × 3): вид не ломается.
- **Меню «Планетарный вид» — 0 из 1** (перекрыто панелью «Склад»).

**Вердикт: переход в PV стабилен на 32 из 32 тел по прямой ссылке и на 32 из 32 по кнопке спуска; возврат «↑ К глобусу» некорректен на 8 из 8.**

## Что проверено и чем

- `node tools/_pvprobe.js` → `_pvprobe.json` — устройство входа: `?pv=earth` (surface 2,1 с), состав `#globe-modal` (кнопка `#globe-surface` с `onclick`-функцией), `window.PlanetView.open`.
- `node tools/_pv_all.js` → `_pv_all.json` — 32 тела × `?pv=<id>` (навигация в одной вкладке, ожидание поверхности, состояние DOM, баннеры).
- `node tools/_pv_matrix.js` → `_pv_matrix.json` — 32 тела × глобус → `#globe-surface`; проверка новых вкладок через `/json/list`, закрытие каждой.
- `node tools/_pv_cycle.js` → `_pv_cycle.json` — 8 тел × (вход, 2 цикла «К глобусу» → спуск, проверка поверхности в новой вкладке) + 24 варианта tilt/zoom/canvas.
- `node tools/_pv_return.js` → `_pv_return.json` — «К глобусу» через 1 с и 5 с, повторный спуск с ручным открытием глобуса (Земля, Титан).
- `node tools/_pv_moons.js` → `_pv_moons.json` — двойной клик по Луне и Титану (глобус `flex`, PV не открывается напрямую).
- `node tools/_pv_diag2.js` → `_pv_diag2.json` — кнопка `#globe-surface`: верх стека `elementsFromPoint`, `onclick` = function, `pointer-events:auto`; клик (и JS, и реальный) закрывает глобус и открывает новую вкладку.

## Что НЕ проверено и почему

1. **Двойной клик по каждому из 32 тел вручную** не выполнялся: для 3 тел (Земля, Луна, Титан) проверен настоящий двойной клик (глобус открылся), для остальных 29 — та же карточка `#globe-modal`, открытая её вкладкой, и та же кнопка спуска. Разницы в коде между телами нет (один `openGlobe(id)` + одна кнопка).
2. **`#pv-loading`** проверить нельзя — элемента нет в DOM; как выглядит индикатор загрузки и есть ли он вообще, по DOM не установить.
3. **`?planet=earth`** проверен только для Земли (0,7 с, поверхность ✓); остальные тела через этот старый параметр не перебирались.
4. **Поведение при блокировке попапов** (fallback `PlanetView.open` в той же вкладке) не воспроизводилось: в headless попапы не блокируются.
5. **Причина 32,1 с у Миранды** не локализована (единичный замер, повторов не делал).
6. **Серверные данные игроков не трогались**, сообщения тестерам не отправлялись, деплой не выполнялся.
