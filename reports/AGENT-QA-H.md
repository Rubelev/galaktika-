`src\galaktika.Web\wwwroot\js\*` → `deploy-host\site\js` (`Copy-Item ... -Force`).

(а) клиент будет каждый раз получать 429 вместо тихого ожидания, (б) **админ из обычной кнопки UI
будет принудительно прогонять событие в обход кулдауна** — это не «осознанная ручная отыгровка».

**Фикс до деплоя:** перенести правку в `src/galaktika.Web/wwwroot/js/world-event-panel.js:81`
(`{ force: true }` → `{}`), затем убедиться, что `deploy-host/site/js` совпадает с `src`
