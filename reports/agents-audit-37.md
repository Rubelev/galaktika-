- **Дата/время:** 2026-11-01, 14:12–14:30 MSK.
- **Сайт:** https://warbattleuniverse.com, build `202611011313`, `js/solar.js?v=1207`.

## 2. Вывод

- **Отключение всех трёх новых скриптов не возвращает 10–20 FPS**: `off=sync,catalog,boot` даёт **4,9–6,5 FPS** (медиана 6,0) против базовых **5,6–6,1** (медиана 5,7). Разница в пределах шума headless (±40 %).
- `off=sync` даже **хуже** базы (2,8–4,9) — но это шум, а не эффект.
- **Виновник — старый рендер или среда**, а не build-sync / catalog-render / system-boot. При равном DOM (732 узла) старый вид держит 3–8 FPS, хотя каталог-режим при 864 узлах даёт ~11 FPS — значит стоимость в самом старом пути отрисовки: 9 планет с текстурами (`background-image`) и фильтрами + 23 луны + анимация `background-position` + `.orbit`-узлы, всё в CSS 3D-трансформации.

## 3. Глобалы (что новое реально грузится в старом виде)

| Переменная | Значение |
|---|---|
| `window.__buildSynced` | **undefined** |
| `window.__catalogClicks` | **undefined** |
| `window.__systems` | **0** (пустой массив/объект) |
| `window.SceneScale` | object ✓ |
| `window.CatalogRender` | **undefined** (в старом виде модуль не подключается) |

То есть в старом виде `build-sync`/`catalog-render` не выставляют своих глобалов (либо не грузятся, либо не публикуют) — и при этом их отключение флагами `?off=` не меняет FPS. Косвенно это подтверждает, что они не участвуют в кадре старого вида.

## 4. Что проверить дальше (предложение)

1. **Заморозить фильтры/анимации планет** в старом виде (`.planet-surface` `filter`, `background-position`-анимация) и сравнить FPS — самый вероятный источник.
2. **Отключить `.orbit`-узлы** (9 штук) — проверить, сколько они стоят.
3. **Сравнить с `?render=canvas`** в старом виде (корабли уже не в DOM) — если FPS вырастет, вклад маркеров/фильтров подтверждается.
4. Для чистоты — прогнать те же 5 вариантов при **включённом GPU** (не `--disable-gpu`), чтобы понять, сколько из 3–8 FPS — стоимость программного рендера.

## Вердикт

- **Просадка FPS старого вида не связана с новыми скриптами**: при `off=sync,catalog,boot` — те же 4,9–6,5 FPS, что и в базе (5,6–6,1).
- **Причина — старый путь отрисовки** (текстуры/фильтры/анимации планет и лун в CSS 3D) и/или программный рендер headless; каталог-режим при большем DOM даёт ~11 FPS.
- **Глобалы** `__buildSynced`, `__catalogClicks` в старом виде не определены, `__systems` = 0, `SceneScale` есть, `CatalogRender` — нет.

## Что не проверено и почему

1. **GPU-прогон** — headless запускался с `--disable-gpu`; сравнение с GPU не делал.
2. **Профилирование старого рендера** (какой именно фильтр/анимация) — не снимал; это следующий шаг, требует отдельного замера с заморозкой стилей.
3. **Серверные данные игроков не трогались**, деплой не выполнялся.
