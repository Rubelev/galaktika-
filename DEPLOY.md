# Развёртывание сервера для тестеров

## Что уже готово в проекте
- `Dockerfile` — двухступенчатая сборка .NET 11 → рантайм
- `render.yaml` — конфиг Render (бесплатный план)
- `fly.toml` — конфиг Fly.io
- `.dockerignore` — мусор не попадает в образ

## Вариант 1. Render (проще всего, без карты)

1. Создать аккаунт на https://render.com (можно через GitHub).
2. Загрузить проект в репозиторий GitHub (или GitLab).
3. Render → **New → Blueprint** → выбрать репозиторий.
   Render прочитает `render.yaml` и создаст сервис сам.
4. Дождаться сборки (5–10 минут, .NET тянет пакеты).
5. Получить адрес вида `https://galaktika.onrender.com` — его и давать тестерам.

**Важно:** бесплатный инстанс засыпает после 15 минут без запросов.
Первый заход после сна — до 30 секунд. Лечится бесплатным пингом:
https://uptimerobot.com → HTTP-монитор на адрес раз в 10 минут.

## Вариант 2. Fly.io

```bash
fly launch --no-deploy
fly deploy
fly open
```

Даёт адрес `https://galaktika.fly.dev`. Нужна привязка карты, но в пределах
бесплатного лимита списаний не будет.

## Вариант 3. Свой VPS (если нужны китайские тестеры)

Материковый Китай требует **ICP 备案** для домена (1–3 недели, нужен паспорт
или китайское юрлицо). Без 备案 сайт заблокируют.
Обход: сервер в **Гонконге** — 备案 не нужен, задержка из материка приемлемая.

Минимальный сервер: 1 ядро, 1 ГБ RAM, Ubuntu 22.04.

```bash
# на сервере
apt update && apt install -y docker.io
git clone <репозиторий> && cd galaktika_final
docker build -t galaktika .
docker run -d --restart=always -p 80:8080 --name galaktika galaktika
```

## Проверка после развёртывания

1. Открыть адрес — должна появиться страница входа.
2. Войти как `test1@test.ru` — проверить флот и биржу.
3. Открыть с телефона — вёрстка не должна ломаться.
4. Проверить, что двое разных людей видят каждый свой профиль.

## Что НЕ работает на сервере сейчас

Профили игроков хранятся **в браузере** (localStorage), а не на сервере.
Следствия:
- у каждого тестера свой прогресс — это нормально;
- но прогресс **не переносится** между устройствами;
- общий рынок, чат и гильдии между игроками пока невозможны.

Чтобы появился настоящий мультиплеер, нужен слой хранения на сервере
(база + API). Это отдельная большая работа.
