# Матрица скоростей флота

Скорость каждого борта считается от базового параметра, а не задаётся вручную.

## Формула

```
v = K · (двигателей · тяга_двигателя · (1 + 0.08 · уровень_двигателя))
        / масса_корпуса
        · (1 + 0.05 · уровень_технологий)
```

| Параметр | Значение |
|---|---|
| `K` | 10 (калибровка: эталонный борт = 100 км/с) |
| Бонус модернизации двигателя | **+8 %** за уровень, максимум 5 |
| Бонус технологий | **+5 %** за уровень, максимум 10 |
| Количество двигателей | учитывается напрямую (2 двигателя = ×2 тяги) |
| Масса | делитель: тяжёлый корпус медленнее |

## Базовые характеристики

| Класс | Масса, т | Двигателей | Тяга одного | Скорость на стоке |
|---|---|---|---|---|
| «Искра» (разведчик) | 45 | 1 | 450 | **100 км/с** |
| «Баржа» (грузовик) | 320 | 2 | 800 | 50 км/с |
| «Стриж» (курьер) | 90 | 2 | 1200 | 266,7 км/с |
| Корсар | 140 | 2 | 1300 | 185,7 км/с |
| «Геолог» (рудный) | 180 | 2 | 1000 | 111,1 км/с |
| Фрегат | 260 | 3 | 1100 | 126,9 км/с |
| Перехватчик | 120 | 3 | 900 | 225 км/с |

## После полной прокачки (двигатель 5, технологии 10)

| Класс | Сток | Максимум | Прирост |
|---|---|---|---|
| «Искра» | 100 | **210** | +110 % |
| «Баржа» | 50 | 105 | +110 % |
| «Стриж» | 266,7 | 560 | +110 % |
| Корсар | 185,7 | 390 | +110 % |
| «Геолог» | 111,1 | 233,3 | +110 % |
| Фрегат | 126,9 | 266,5 | +110 % |
| Перехватчик | 225 | 472,5 | +110 % |

Полный бонус = (1 + 0,08·5) · (1 + 0,05·10) = 1,4 · 1,5 = **×2,1**.

## Где применяется

- Время рейса флота: `durGame = distKm / speedKmS(art, {engineLevel, techLevel})`.
- Модернизация двигателя в профиле: поле `engineLevel` (0…5).
- Исследования: поле `techLevel` (0…10).

## Проверка

```
?speeds=1  →  матрица «сток» и «максимум» в заголовке страницы
```

Пример вывода: `сток jet_scout:100 jet_hauler:50 ion_courier:266.7 …`
