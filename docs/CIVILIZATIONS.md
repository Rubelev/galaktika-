# Боты-цивилизации: как устроены и сколько у них свободы

## 1. Зачем

В игре 6 цивилизаций должны жить сами: производить, торговать, воевать, расширяться.
Но «умный ИИ» без ограничений ломает экономику за сутки, поэтому у каждой цивилизации
есть **доля свободных действий** — часть решений принимает детерминированный сценарий
фракции, часть — взвешенный выбор бота.

## 2. Шесть цивилизаций

| id | Название | Фракция | Автономия | Агрессия | Девиз |
|---|---|---|---|---|---|
| `earth` | Земля | federation | **30 %** | 0,25 | Порядок через изобилие |
| `mars` | Марс | republic | **35 %** | 0,35 | Свобода через труд |
| `belt` | Пояс | union | **40 %** | 0,30 | Кто копает — тот решает |
| `tiran` | Тиран | corpo | **25 %** | 0,55 | Всё имеет цену |
| `war_guilds` | Гильдии Вармира | guild | **45 %** | 0,80 | Слава дороже жизни |
| `tarsis` | Лига Тарсиса | league | **50 %** | 0,30 | Скорость — это свобода |

Параметры — в `db/galaktika.db → civilization`, оттуда генерируются
`lib/civ_data.php` и `js/civilizations.js`. Один источник истины.

## 3. Как принимается решение

```
3 действия за тик (10 минут)
 ├─ scripted: (1 − autonomy_pct) × 3 — по приоритетам фракции
 └─ free:     autonomy_pct × 3      — взвешенный выбор из ДОСТУПНЫХ действий
```

**Сценарий фракции** (детерминированный, по параметрам):

| Признак | Что добавляется в приоритет |
|---|---|
| агрессия ≥ 0,6 | `raid`, `recruit` |
| жадность ≥ 0,6 | `trade`, `produce` |
| технологии ≥ 0,7 | `research` |
| всегда | `produce`, `fortify`, `expand` |

**Свободное действие** — выбор из пула, где ресурсы позволяют действие.
ГСЧ засеян: `sha256(seed + номер_тика + соль)`, поэтому тик **воспроизводим**:
один и тот же вход даёт один и тот же результат.

## 4. Каталог действий

| Действие | Условие | Эффект |
|---|---|---|
| `produce` | — | +6 000 кр, +120 еды |
| `trade` | — | +9 000 кр |
| `recruit` | 8 000 кр | +3 флота |
| `fortify` | 5 000 кр | +2 влияния |
| `research` | 12 000 кр | +3 влияния, −12 000 кр |
| `expand` | 40 000 кр, территория < 12 | +1 территория, −40 000 кр |
| `raid` | флот ≥ 5 | +15 000 кр, −1 флот, −50 еды, −1 влияние |

## 5. Защита от «печатного станка»

```
1. Кредиты и еда не могут уйти в минус (max(0, …)).
2. Потолки: флот ≤ 400, влияние ≤ 200, территория ≤ 12, население ≤ 5 млн.
3. Расширение — не больше одной клетки за тик.
4. Рейд требует флота и стоит топлива/влияния.
5. Боты НЕ читают профили игроков, не отбирают корабли и колонии,
   не меняют цены рынка напрямую.
6. Все действия пишутся в civ-log.json (последние 400).
```

## 6. Измерение автономии

`civ_autonomy_report()` считает по журналу: сколько действий было свободными.
Это **фактическая** доля, а не заданная — её видно в `civ_status`.

Живой замер после первого тика:

```
свободных 7 / плановых 11 → фактическая автономия 38,9 %
по цивилизациям: 25–50 % (совпадает с настройкой)
```

## 7. API

| Метод | Что отдаёт |
|---|---|
| `civ_status` | 6 цивилизаций: параметры, состояние, тики, фактическая автономия |
| `civ_log` | последние 50 действий с суммами |
| `civ_tick` | принудительный тик (только администратор) |

## 8. Расписание

```
cron: */10 * * * * php data/bin/civ-tick.php
```

Скрипт сам проверяет `CIV_TICK_SEC = 600` — двойной запуск не сломает состояние.

## 9. Что проверено (23/23)

```
OK 6 цивилизаций, id уникальны
OK autonomy_pct в (0,1), разброс ≥ 0,2
OK ГСЧ воспроизводим и зависит от тика
OK свободных действий = round(3 × autonomy)
OK нет отрицательных ресурсов, границы соблюдены
OK raid без флота / expand без денег / expand при максимуме — запрещены
OK тик детерминирован (два прогона совпали)
OK состояние — валидный JSON, есть tick_no
OK civ_core не трогает users.json и профили
```

## 10. Что не сделано (честно)

| Что | Статус |
|---|---|
| Войны между цивилизациями | ❌ рейды есть, взаимных боёв нет |
| Дипломатия и союзы | ❌ |
| Влияние на цены рынка | ❌ боты не торгуют с игроками |
| Отображение в интерфейсе | ⏳ данные есть (`civilizations.js`), панели нет |
| Долгий прогон (сутки) | ❌ проверены 1–2 тика |
