# Боевая система «Галактики»

Документ фиксирует математику боя: характеристики кораблей, типы оружия, таблицу
сопротивлений, формулу урона, влияние модернизаций и дополнительных пушек.
Все числа отсюда используются и сервером (`api.php → combat_sim`), и клиентом
(`js/combat3d.js`) — чтобы картинка и расчёт не расходились.

## 3. Таблица сопротивлений

Множитель урона по типу защиты:

| Тип оружия | по щиту | по броне |
|---|---|---|
| Кинетика | **0,55** | 0,95 |
| Тепло | 1,20 | **0,70** |
| Взрыв | 0,75 | **1,25** |
| Энергия | **1,45** | 0,80 |

Читается так: **кинетика плохо бьёт по щитам** (щит рассеивает удар), **энергия
жжёт щит**, но броня держит её хуже, чем взрыв.

## 4. Формула урона

Для одного выстрела:

```
урон_базовый   = D × (1 + 0,12 × lvl_оружия)
попадание      = clamp(acc × (1 + 0,04 × lvl_оружия) × (1 − 0,04 × (пушки − 1)), 0,25, 0,98)
уклонение      = попадание × (1 − evade)
урон_по_щиту   = урон_базовый × resist_щит × (1 + 0,18 × lvl_щита_врага)
урон_по_броне  = урон_базовый × resist_броня × (1 − armor × (1 − pen) × (1 + 0,08 × lvl_брони_врага))
урон_по_корпусу= урон_базовый × 1,00
```

Порядок: сначала щит, остаток — броня, остаток — корпус.
Каждый раунд щит восстанавливается на `shield × (0,05 + 0,20 × lvl_щита)`.

## 5. Модернизации (до 3 уровней каждая)

| Модернизация | Эффект за уровень |
|---|---|
| Оружие | +12 % урона, +4 % точности |
| Щит | +18 % ёмкости, +20 % регенерации |
| Броня | +8 % к сопротивлению брони |
| Двигатель | +6 % уклонения |

## 6. Дополнительные пушки

Вторая и следующие пушки дают **полный урон**, но снижают точность залпа:

```
точность_залпа = acc × (1 − 0,04 × (пушки − 1))
```

| Пушек | Множитель урона | Штраф точности | Итог по урону |
|---|---|---|---|
| 1 | ×1,00 | 0 % | 1,00 |
| 2 | ×2,00 | −4 % | **1,92** |
| 3 | ×3,00 | −8 % | **2,76** |
| 4 | ×4,00 | −12 % | **3,52** |
| 5 | ×5,00 | −16 % | **4,20** |

Ограничение — энергия корабля: 5 лазеров требуют 150 при запасе «Титана» 260.

## 8. Проверка примера

Фрегат «Щит» (щит 2 000, броня 0,35, уклонение 0,08) против ланцера с двумя
лазерами (урон 260, точность 0,75, пробитие 0,20):

```
попадание = 0,75 × (1 − 0,04) = 0,72
с уклонением 0,72 × 0,92 = 0,662
урон по щиту за выстрел = 260 × 1,45 = 377
выстрелов в раунд = 1,5 × 2 = 3
щит 2 000 / (377 × 3 × 0,662) ≈ 2,7 раунда на снятие щита
дальше по броне: 260 × 0,80 × (1 − 0,35×0,80) = 149 за выстрел
корпус 4 200 / (149 × 3 × 0,662) ≈ 14,2 раунда
итого ≈ 17 раундов до уничтожения
```
