# Экономика зрелищ: Вармир и Тарсис

## Принцип

Любое событие — это **гости**, а гости требуют:

| На гостя | Норма | Цена |
|---|---|---|
| Еда | 0,3 кг/сутки | 12 кр/кг (заводская) |
| Вода | 3 л/сутки | 7 кр/л |
| Энергия | 1,5–3,2 кВт·ч | 2 кр/кВт·ч |
| Деликатесы | 32 % гостей | ×10 к заводской еде |

Доход: **билеты + маржа ставок + деликатесы**. Постоянные расходы: персонал,
призовой фонд, обслуживание арены.

## Формулы (в `lib/world_econ.php`)

```
доход  = гости·билет + гости·оборот_ставок·маржа + гости·lux_share·0,3·12·10
расход = гости·0,3·12 + гости·3·7 + гости·кВт·2 + персонал·ставка + приз + обслуживание
маржа  = прибыль / доход
безубыт = постоянные / (доход_на_гостя − расход_на_гостя)
```

## Проверки (23 из 23)

- полная арена всех арен прибыльна;
- пустая — в убытке, и расходы равны постоянным;
- на пороге безубыточности прибыль ≈ 0 (±2 %);
- половина зала прибыльна, но меньше полного;
- деликатесы дают > 5 % выручки (сейчас ~5,5–6 %);
- сводка по миру: полная загрузка 6 650 240, половинная 1 595 620.

## Что дальше

1. **Тик события**: раз в 6 часов (гонки) и по расписанию арен — начислять выручку,
   списывать еду/воду/энергию, платить персоналу.
2. **Билеты**: продажа мест игрокам, динамическая цена по заполняемости.
3. **Ставки**: игроки делают ставки, маржа — доход мира.
4. **Дефицит**: если еды нет — гости уходят, выручка падает, репутация тоже.
