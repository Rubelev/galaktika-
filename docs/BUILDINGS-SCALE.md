# Масштаб построек: расчёт

Все числа — от реальных норм. Население колонии в игре — **~8 000 человек**, от него и считаем.

## 1. Жилой модуль — это город

| Параметр | Значение | Откуда |
|---|---|---|
| Жилая норма | 25 м²/чел | комфортное жильё |
| Нужно площади | 8 000 × 25 = **200 000 м²** | |
| Этажей | 12 | выше — дороже лифты |
| Пятно застройки | 200 000 / 12 = 16 700 м² | 130 × 130 м |
| Высота этажа | 3,2 м | |
| Высота здания | 12 × 3,2 + техэтаж 6 м = **44,4 м** | |
| Квартир | 8 000 / 2,5 чел = **3 200** | средняя семья |
| Помещений в квартире | 4 (2 комнаты, кухня, санузел) | |
| Квартирных помещений | 12 800 | |
| Коридоры, лифты, техпомещения | +32 % | |
| **Всего помещений** | **≈ 16 900** | |
| Объём | 200 000 × 3,2 = **640 000 м³** | |

### Обслуживание

| Ресурс | Расход |
|---|---|
| Вода | 150 л/чел/сутки → **1 200 т/сутки** |
| Кислород | 0,85 кг/чел/сутки → **6,8 т/сутки** |
| Электричество | 2,5 кВт/чел → **20 МВт** |
| Мусор | 1,2 кг/чел/сутки → 9,6 т/сутки |

## 2. Фабрика

| Параметр | Значение |
|---|---|
| Рабочих | 1 000 в смену, 3 смены = 3 000 |
| Норма площади | 40 м²/чел (станки, проходы, склады) |
| Цех | **40 000 м²** → 200 × 200 м |
| Высота цеха | 18 м (краны, вентиляция) |
| Объём | **720 000 м³** |
| Энергия | **50 МВт** |
| Охлаждение | 1 500 м³/ч воды |
| Трубы | 3–4 по 90 м высотой, диаметр 8 м |
| Помещений (участки, склады, бытовки) | **≈ 900** |

## 3. Термоядерная станция

### Энергия и тепло

| Параметр | Значение |
|---|---|
| Электрическая мощность | **1 ГВт** (город + фабрика + запас) |
| КПД | 40 % |
| Тепло, которое надо сбросить | **1,5 ГВт** |

### На планете — испарительные градирни

| Параметр | Значение |
|---|---|
| Теплота парообразования | 2,26 МДж/кг |
| Эффективность испарения | 70 % |
| Расход на испарение | 1,5 ГВт / (2,26 × 0,7) = **0,95 т/с ≈ 3 400 т/ч** |
| Подпитка (потери на испарение 1 %) | **34 т/ч** |
| Число градирен | 4 (по 375 МВт) |
| Высота градирни | **120 м** |
| Диаметр основания | **100 м** |
| Площадь под 4 градирни | ≈ 0,12 км² |

### На Луне — сухое охлаждение (воды нет)

| Параметр | Значение |
|---|---|
| Излучение при 350 K | σT⁴ = 850 Вт/м² (с одной стороны) |
| С двух сторон панели | 1 700 Вт/м² |
| Нужная площадь | 1,5 ГВт / 1 700 = **≈ 880 000 м² = 0,88 км²** |
| Масса панелей (5 кг/м²) | **4 400 т** |
| Сравнение | это 123 футбольных поля |

Именно поэтому на Луне станция — не башня с градирнями, а **плоское поле радиаторов**.

## 5. Доки

| Элемент | Размер |
|---|---|
| Сухие доки под колосс | 4 × (400 × 200 × 60 м) |
| Кран | 500 т, высота 80 м |
| Ремонтные мастерские | 200 помещений × 150 м² = **30 000 м²** |
| Склады запчастей | 100 000 м² |
| Энергия доков | 200 МВт |
| **Общая территория** | **≈ 6 км²** |

Доки в три раза больше космопорта — потому что там не только стоянка, но и разборка корпуса, замена реактора, покраска.

## 6. Сводка: как это выглядит рядом

| Объект | Размер | Площадь |
|---|---|---|
| Человек | 1,8 м | — |
| Жилой модуль | 130 × 130 × 44 м | 0,017 км² |
| Фабрика | 200 × 200 × 18 м | 0,04 км² |
| Термоядерная станция (планета) | 400 × 400 м + 4 градирни | 0,16 км² |
| Термоядерная станция (луна) | радиаторное поле | **0,88 км²** |
| Космопорт | 1,5 × 1,3 км | **2 км²** |
| Доки | 2 × 3 км | **6 км²** |

Для сравнения: Ватикан — 0,44 км², аэропорт Шереметьево — 30 км².

## 7. Что это значит для модели в игре

Кубик 0,5 м удобен для деталей, но жилой модуль в нём — 260 кубиков в ширину. Поэтому:

- в каталоге постройки показаны **как схемы** (1 кубик ≈ 2 м);
- настоящие размеры подписаны в карточке постройки;
- рядом стоит **человечек 1,8 м** — чтобы чувствовать масштаб.
