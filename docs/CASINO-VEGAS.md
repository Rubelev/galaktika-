# Кеп-Вегас: зоны, залы, игры

Идея: **играем везде и во всё**. Пять зон на разных телах системы — от бронзового зала
на Церере до стола в невесомости. 129 игр, 16 залов, у каждого зала своя ставка и атмосфера.

## 3. Игры (129)

### Рулетки — 6 вариантов

| Игра | Правило | Edge |
|---|---|---|
| Европейская | 37 лунок | **2,70 %** |
| Французская (La Partage) | половина ставки при зеро | **1,35 %** |
| Американская | 38 лунок, два зеро | **5,26 %** |
| Русская | 36 номеров, комиссия 5 % с выигрыша | **7,64 %** |
| Мини-рулетка | 13 лунок | **7,69 %** |
| Молнийная | множители ×50–×500 на номер, 3 % шанс | 2,70 % базово |

### Автоматы — 100

10 тем × 10 автоматов: однорукий бандит, неон, космос, океан, Египет, кибер, мифы,
конфеты, Дикий Запад, Пустота. RTP **92 % → 98 %** шагом 0,6 п.п.
Математика: 3 барабана, пара ×2,5, трио ×16…×23, джекпот-трио ×100.

### Карты — 5

| Игра | Правила | Edge |
|---|---|---|
| Блэкджек | дилер стоит на 17, блэкджек 3:2 | ~0,5 % |
| Блэкджек-свитч | можно переключать карту | ~0,35 % |
| Три-карточный покер | пара, флеш, стрит, сет | ~3,3 % |
| Техасский холдем | против дилера | ~2,5 % |
| Бридж | ставка на пару в турнире | ~2 % |

### Скачки — 6 треков

8 гибридов на каждом: Робо-конь «Болт», Метановый скакун, Ледяной бегун,
Грави-борзая, Клон-жеребец, Дюнный бегун, Био-мул, Пустотный иноходец.
Тотализатор: казино забирает **15 %** пула.

### Спорт — 12 дисциплин

Спринт, марафон, дуэль, прыжок с орбиты, борьба в невесомости, заплыв в океане Европы,
тяжёлая атлетика, гимнастика, фехтование, стрельба из лука, гребля, эстафета.
Люди и андроиды в одном зачёте. Маржа **5 %**.

## 4. Графика и места (концепт)

| Зона | Палитра | Материалы | Свет | Звук |
|---|---|---|---|---|
| Рулетки | бордо, латунь, тёмное дерево | сукно, медь, хрусталь | тёплые лампы, блики на колесе | щелчок шарика, джаз |
| Автоматы | неон: циан, маджента, лайм | пластик, стекло, голограммы | стробоскоп, экраны | синтвейв, звон монет |
| Карты | зелёное сукно, дуб, дым | кожа, виски, пепельницы | приглушённый тёплый | тишина, шелест карт |
| Скачки | пыль/лёд/метан: охра, синий, бирюза | трибуны, грязь, пар | солнце/прожекторы | топот, гул толпы |
| Спорт | олимпийский белый, красный, золото | бетон, металл, андроиды | прожекторы арены | гимн, свисток, рёв |

**Места:** каждая зона — отдельная сцена с камерой от первого лица, вход через лифт/шлюз.
Зал Пустоты — стол в невесомости, шарик летит по прямой.
Ледяной трек — гибриды скользят, ставки на «кто упадёт».

## 5. Прогрессия доступа

```
Тир 1 (бронза)   — доступен всем
Тир 2 (серебро)  — после 10 ставок или 50 000 оборота
Тир 3 (золото)   — после 100 ставок
Тир 4 (платина)  — 500 ставок или приглашение
Тир 5 (Пустота)  — только по приглашению, один стол
```

## 7. Проверено (29/29)

```
OK 5 зон, 16 залов, 129 игр (6/100/5/6/12)
OK edge рулеток ≈ каталогу (Монте-Карло, ±1,5 п.п.)
OK RTP автоматов ≈ каталогу (±3 п.п.)
OK блэкджек RTP 93,2 % (в допуске 90–102)
OK покер: пара/сет/флеш/стрит распознаются
OK 8 гибридов, коэффициенты растут
OK 12 дисциплин, маржа 5 %
OK лимиты растут по тирам, min < max
```
