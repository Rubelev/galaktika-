## Осталось починить

| Баг | Причина / план |
|---|---|
| Ресурсы не обновляются после сделок и стройки | Нужен общий хук `pullServerProfile()` после каждой сделки |
| Первая продажа не обновляет кредиты до второго клика | Тот же хук |
| Ветровая электростанция не списала 4 чипа | В `factory_table` нет позиции `wind` — сверить таблицы клиента и сервера |
| Разведка требует разведчик, кнопка доступна | Заблокировать кнопку или разрешить без корабля |
| Аренда дока: 50 000 в одном окне, 75 000 в другом | Свести к одной константе из сервера |
| Звание «Торговец» получено, прогресс 196 320 / 200 000 | Проверка ранга считает по одному счётчику, награда по другому |
| Раздел «Tasks» пуст | Нет заданий в источнике — заполнить или скрыть раздел |
| Пролог запускается заново в Story/Quests/Codex | Флаг «пролог пройден» не сохраняется в профиле |
| «Иo: 0.0 млрд → 1 массивов» | Склонение и округление в сводке колоний |
| «18 ресурсов» против реального склада | Наставник считает виды, а не количество |
| Кнопки EN подсвечена при русском UI | Скрыть переключатель, пока нет перевода |
| 401 на `/api/auth/me` до входа | Не дёргать профиль без токена (частично закрыто в обучении) |
| Кредиты 80 000 → 205 000 молча | Найти автоначисление (тестовый код в solar.js) и убрать |
| Одно уведомление показывается дважды | Дедупликация в `notify()` |
| `.store` идёт на `.com` без предупреждения | Решено: `.store` — зеркало, предупреждение остаётся |
