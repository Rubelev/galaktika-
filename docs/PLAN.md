### Что осталось (приоритет)

1. **2.2** — связать `fleet-N` с `agent.id` каталога, убрать наложение маркеров в одной точке.
2. **Этап 3 (Тарсис)** — выбор мира строго по id; зоны: кратеры, каньон, серпантин, пустоши; стартовая арка, маяки, кольцо 3 круга.
3. **Этап 4** — клонарня с таймером 60–147 мин, страница боя `?ww-fight=1`, арены в каталоге.
4. **Этап 5** — объекты станции в PV (склад, терминалы, щитовая), маяк и сирена, провал по таймеру.
5. **Perf** — замер в браузере игрока (`?perf2=1`), затем решение об оптимизации текстур/фильтров.

### Правила, заработавшие в цикле

- деплой только после проверки синтаксиса JS (страж в `deploy.ps1`);
- FPS мерить только в реальном времени (CDP), не с `--virtual-time-budget`;
- одна функция масштаба (`js/scene-scale.js`), без копий в модулях;
- данные объектов — в SQL, в коде только чтение;
- каждая правка — с числом приёмки.

Правило: **никаких правок «на бегу»**. Каждый шаг — с критерием приёмки.
Шаг считается сделанным только когда критерий подтверждён числами или скриншотом.
