# Уход игрока: автопилот, упадок и повторная колонизация

## 1. Отметка активности

- в профиль добавляется `lastSeen` (обновляется при входе и при любом авторизованном запросе);
- «игрок ушёл» = нет активности N суток; порог задаётся в настройках, по умолчанию 3 суток.

## 2. Жизненный цикл колонии

| Фаза | Дней без входа | Что происходит с колонией |
|---|---|---|
| **Активна** | 0–3 | всё как сейчас: налоги, рост, налёты |
| **Автопилот** | 3–14 | налоги игроку не идут (он их не забирает), население −0,2 %/день, счастье −0,5/день, налёты чаще (раз в 12 ч), оборона работает |
| **Упадок** | 14–30 | население −2 %/день, каждые 5 дней одно сооружение теряет уровень, склады тают на 10 %/день, счастье → 0 |
| **Дикость** | 30+ (календарный месяц) | население падает до 2–5 % от прежнего, все сооружения — руины, колония снимается с игрока и уходит в реестр брошенных |

Всё это считает серверный cron (раз в 10 минут), а не браузер: иначе ушедший игрок «замораживал» бы колонию.

## 3. Реестр брошенных миров

Файл `worlds.json`, запись:

```json
{
  "id": "w-7f3a",
  "name": "Новый Кеплер",
  "owner": "ab@btema.ru",
  "abandonedAt": 1793150000,
  "snapshot": {
    "population": 820000,
    "factories": { "robots": 2, "equipment": 1 },
    "ships": 4,
    "resources": { "steel": 1200, "grain": 40000 }
  }
}
```

**Богатство остатков** — сколько цивилизация оставила потомкам:

```
richness = clamp(1 − (дней_с_момента_броска − 30) / 60, 0, 1)
```

| Дней в забросе | 30 | 45 | 60 | 75 | 90+ |
|---|---|---|---|---|---|
| richness | 100 % | 75 % | 50 % | 25 % | 0 % |

## 4. Колонизация чужой колонии

Условия: у игрока нет своей колонии, есть 200 000 кр, мир свободен, это не его собственный мир.

Что получает новый владелец:

| Что | Сколько остаётся |
|---|---|
| Население | `snapshot.population × richness × 0,05` (2–5 % прежнего) |
| Сооружения | каждое сохраняется с шансом `richness` как **руина**: сразу не работает, в колонии появляется кнопка «Восстановить» (цена — 50 % от постройки). Восстановление даёт **1 уровень**, а если мир брошен недавно (richness ≥ 0,75) — **2 уровня**. После восстановления кнопка исчезает |
| Склад | `richness × 10 %` прежних ресурсов |
| Оборона | 0 (её сносит время) |
| Название | можно оставить прежнее или переименовать |

## 5. Если прежний владелец вернулся

- **30 дней** после броска мир зарезервирован за прежним хозяином: он возвращает его бесплатно, остальным система отвечает «зарезервирован до ДД.ММ.ГГГГ»;
- после резерва мир открыт всем за 200 000 кр;
- колонию уже заняли → **начинает всё с нуля**: кредиты 250 000, без колонии, построек, кораблей и склада. При следующем входе игра показывает сообщение «Колонию забрали, пока вас не было. Вы начинаете заново».

## 6. Реализация

| Часть | Что делать |
|---|---|
| cron | `world-tick.php` раз в 10 минут: обход `users.json`, перевод колоний по фазам, вынос брошенных в `worlds.json` |
| API | `GET /api/worlds/abandoned` — список с богатством; `POST /api/colony/colonize {worldId}` — занять мир |
| Профиль | `lastSeen`, флаги `colony.state`, `colony.ruins` |
| UI | экран «Миры»: брошенные колонии, остатки, кнопка «Колонизировать 200 000 кр»; в колонии — блок руин с ценой восстановления |

## 7. Крайние случаи

- **Своя брошенная колония** — колонизировать нельзя (проверка по email).
- **Два игрока одновременно** — мир занимается атомарно: кто первый, того и мир, второй получает «уже занято».
- **Бросил, пока платил** — колонизация списывает кредиты только при успешном захвате.
- **Нагрузка** — обход 1000 профилей раз в 10 минут для PHP-скрипта на cron приемлем.
- **Возврат после 7 дней** — мир остаётся в реестре, но прежний владелец уже не имеет приоритета.

## 8. Что даёт игре

- мир не «застывает»: заброшенные колонии живут, деградируют и освобождают место;
- новичок получает не пустую планету, а руины с историей — и это дешевле, чем строить с нуля;
- появляется причина возвращаться: колонию могут забрать, пока тебя нет.
