# Каталог типов вселенной и SQL-база

Цель: новая солнечная система собирается **из каталога типов**, а не пишется заново.
Все параметры — в SQLite: `db/galaktika.db` (схема `db/schema.sql`, данные `db/seed.sql`).

## Таблицы

| Таблица | Что хранит |
|---|---|
| `system_type` | назначение системы: гонки / война / дом |
| `system` | конкретная система: звезда, масштаб времени, **px_per_au** (единая шкала) |
| `body_type` | тип тела: звезда, скалистая, газовый гигант, лёд, луна, пояс, врата |
| `body` | тело: родитель, орбита (а.е., период, эпоха, наклон), радиус, цвет, **роль** |
| `body_resource` | ресурсы на теле и их обилие |
| `route` | маршрут: откуда/куда, вид, длина, прогиб |
| `ship_class` | **физика кораблей**: ускорение, потолок в долях c, HP, груз |
| `module_type` | модули болидов по слотам |
| `artifact_type` | артефакты из других миров |
| `race_event` | заезд: арена, период, длительность, круги |
| `clone_set` | наборы клонов Вармира |
| `weapon_type` | супер-оружие клонов |
| `physics_rule` | **свод правил**: предел 0,95 c, масштаб времени, px/а.е. |

## Роли тел (`body.role`)

`arena` · `factory` · `workshop` · `betting` · `scrapyard` · `front` · `home` · `star`

Одна и та же механика (гонки, война, экономика) собирается из тел с нужными ролями —
не нужно писать отдельный код под каждую систему.

## Как добавить новую систему

1. `INSERT INTO system` — имя, тип, звезда, `px_per_au`.
2. `INSERT INTO body` — тела с `parent_id`, орбитой и **ролью**.
3. `INSERT INTO route` — маршруты между телами.
4. Если система гоночная — `race_event` с ареной.
5. Если военная — тела с ролью `front`, клоны и оружие берутся из общего каталога.

Код читает одни и те же таблицы → **одни и те же правила физики и отрисовки** для любой системы.

## Свод правил (таблица `physics_rule`)

| id | Значение | Смысл |
|---|---|---|
| `max_c` | 0,95 | предел скорости |
| `time_scale` | 1 | глобальный масштаб времени (моделирование — одной константой) |
| `px_per_au` | 185 | единая шкала сцены |

Классы кораблей (`ship_class`): fighter 150 км/с² / 0,30 c · light 80 / 0,25 c ·
hauler 30 / 0,15 c · heavy 15 / 0,10 c.
