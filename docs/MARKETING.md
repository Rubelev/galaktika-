# Маркетинг «Галактики»: проверка на рыночный успех и программа продвижения

**Проект:** «Галактика» — массовый продукт (браузерная космическая стратегия).
**Общий репозиторий 1С — не трогаем:** маркетинг там не нужен, это внутренние проекты.

---

## 1. Роль маркетолога в проекте

```
Миссия: привести игрока и доказать экономику привлечения числом.
Границы: не меняет баланс, цены, данные игроков и код —
         только оффер, каналы, контент, аналитика и удержание.
```

---

## 2. Критерий рыночного успеха (решается ДО продвижения)

| Уровень | Метрика | Порог «успех» | Где берём |
|---|---|---|---|
| Вход | регистрации / визиты (CR) | **≥ 5 %** | сервер: users + счётчик визитов |
| Активация | сыграл первый бой / регистрации | **≥ 40 %** | world_tick, casino | 
| Возврат | D1 | **≥ 25 %** | повторный вход через сутки |
| Возврат | D7 | **≥ 10 %** | повторный вход через 7 дней |
| Деньги | платящих / активных | **≥ 2 %** | pay-orders |
| Экономика | LTV / CAC | **≥ 3** | доход / расход канала |
| Продукт | средняя сессия | **≥ 10 мин** | presence/логи |

**Правило:** если хотя бы один уровень ниже порога — сначала правим продукт,
потом льём трафик. Реклама не лечит плохую активацию.

---

## 3. Программа продвижения (первые 30 дней)

| Неделя | Что делаем | Метрика |
|---|---|---|
| 1 | Аудит воронки: где отваливается регистрация; починить вход и первый экран | CR, активация |
| 2 | Позиционирование: 1 предложение + 3 выгоды + 5 скриншотов; лендинг | понятность на 5 людях |
| 3 | 2 бесплатных канала (сообщество, devlog) + 1 платный тест на малый бюджет | CPA по каждому |
| 4 | Удержание: что мешает вернуться на 2-й день; одно исправление | D1 |

**Каналы (по приоритету):**
```
1. Тематические сообщества (космос, стратегии, инди) — 0 ₽, органика.
2. Devlog: 1 пост в 2 дня с реальным прогрессом и скриншотами.
3. Короткие видео 15–30 с: бой, заезд, казино — 1 в неделю.
4. Платный тест: минимальный бюджет, один канал, UTM-метки.
```

## 5. Правила честности

```
1. Каждая цифра — с источником и периодом.
2. Гипотеза проверяется тестом, а не спором.
3. Один канал за раз — иначе непонятно, что сработало.
4. «Нет данных» — законный ответ; выдуманное «проверено» дороже.
5. Провал теста — результат: пишется с числом и выводом.
```
