# Система проектирования: детали, 3D-модель и векторный чертёж

## Зачем

Блочные сцены годятся для декораций, но инженерную станцию из кубов не собрать:
нет несущего каркаса, связей, оборудования. Поэтому добавлен слой **параметрических деталей**:
модель описывается списком деталей с размерами, из неё строятся **3D-модель** и **векторный чертёж**.

## Детали (14 типов)

| Тип | Что это | Параметры |
|---|---|---|
| `pad` | фундаментная плита | w, h, d |
| `slab` | перекрытие | w, h, d |
| `column` | колонна | w, h, d |
| `beam` | балка связи | w, h, d |
| `truss` | ферма с раскосами | w, h |
| `ring` | кольцевая площадка | r |
| `tank` | резервуар с крышкой | r, h |
| `ladder` | лестница со ступенями | h |
| `pipe` | труба с фланцем | r, h |
| `cable` | кабельная трасса | w |
| `antenna` | мачта с кольцами | h, r |
| `gantry` | кран-балка с тельфером и крюком | w, h, offset |
| `rail` | ограждение/рельс | w, h, d |
| `winch` | лебёдка с барабаном | — |

Координаты — в метрах, `x` вправо, `y` вверх, `z` на зрителя. Поворот — `rot: [x, y, z]` в градусах.

## Модель

```json
{
  "title": "Гравитационная платформа «Галактика-1»",
  "parts": [
    { "type": "pad",    "x": 0, "y": 0,  "z": 0, "w": 26, "h": 1, "d": 26 },
    { "type": "column", "x": -8, "y": 18, "z": -8, "w": 1.6, "h": 34, "d": 1.6 },
    { "type": "truss",  "x": 0, "y": 12, "z": -8, "w": 16, "h": 1.4 },
    { "type": "gantry", "x": 0, "y": 44, "z": 0, "w": 20, "h": 12 }
  ]
}
```

Модель хранится в профиле игрока (`/api/design/save`, `/api/design/load`),
сервер проверяет типы деталей, зажимает размеры в ±500 м, ограничивает 400 деталями.

## Чертёж (SVG)

Строится автоматически из модели, без картинок:

- **вид сбоку (X–Y)** с линией земли, осевой линией;
- **вид сверху (X–Z)** с эллипсами деталей;
- **размеры** с засечками: высота H и длина L, в метрах;
- **штриховка** бетона, отдельные цвета для каркаса и кранового оборудования;
- **штамп**: название, лист, стадия П, масштаб, габариты, число деталей, состав систем;
- **легенда слоёв** и **примечания** (фундамент, каркас, кран, шахта).

Масштаб подбирается автоматически под габариты, поэтому лист не «разъезжается».

## Как открыть

Меню → **📐 Проектирование**. Внутри две вкладки: «3D-модель» и «Чертёж».
Проверить напрямую:

- 3D: `https://warbattleuniverse.com/?design=1&notutor=1`
- чертёж: `https://warbattleuniverse.com/?design=1&notutor=1&tab=dwg`

## Модель станции по умолчанию

| Узел | Состав |
|---|---|
| Фундамент | плита 26×26×1 м, 4 сваи 2×2×3 м |
| Каркас | 4 колонны 34 м, 16 балок связей через 8 м |
| Связи | 2 фермы с раскосами |
| Шахта | колонна 3×34×3 м, лестница 34 м |
| Площадки | кольца r = 5 / 5,6 / 6,2 м на высотах 10 / 18 / 26 м |
| Верх | перекрытие 14×14 м, кольцо r = 6,5 м |
| Кран | кран-балка 20×12 м, лебёдка |
| Оборудование | 2 трубы, 2 резервуара, кабельная трасса, антенна, рельс |
| Итого | 43 детали, габарит 26,2 × 26,0 × 50,5 м |
