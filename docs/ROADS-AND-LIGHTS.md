# Дороги и фонари: правила авто-инфраструктуры

Когда игрок ставит постройку, инфраструктура вокруг неё строится **сама**.
Ниже — правила, по которым это происходит (`js/infrastructure.js`).

## 1. Классы дорог

| Класс | Ширина | Фонари | Где применяется |
|---|---|---|---|
| **Проезд** | 5 м | с одной стороны | от ворот постройки до улицы |
| **Улица** | 8 м | с одной стороны | подъезд от постройки до магистрали |
| **Магистраль** | 12 м | с двух сторон | две оси через центр мира |

Шаг городской сетки — **20 м**. Все координаты дорог выравниваются по этой сетке,
чтобы кварталы получались ровными.

## 2. Правило доступа

> **У каждой постройки должна быть дорога не дальше 40 м.**

Если ближайшая дорога дальше — постройка считается «без доступа», планировщик
записывает нарушение в `plan.violations`.

## 3. Как прокладывается подъезд

1. Находится ближайшая магистраль (по осям X и Z).
2. От постройки строится **Г-образный маршрут**: сначала поперёк, потом вдоль.
3. Если полоса занята другой постройкой, дорога сдвигается на соседнюю полосу
   сетки (±20, ±40 м).
4. Если сдвиг нужен, добавляется короткий **проезд** от ворот до новой полосы.

## 4. Фонари

| Правило | Значение |
|---|---|
| Шаг вдоль дороги | **28 м** (с запасом ×1,6 для длинных улиц) |
| Отступ от края полотна | **1,2 м** за бордюром |
| Минимум до стены постройки | **8 м** |
| Минимум между фонарями | **7 м** (дубли отбрасываются) |
| На магистрали | с двух сторон |
| У пересечений | фонарь ставится всегда |

## 5. Запреты

| Запрет | Причина |
|---|---|
| Дорога **по воде** | нужен мост, а не асфальт |
| Уклон больше **12 %** | машины не поднимутся, зимой не проедут |
| Дорога за границей острова (**42 м**) | там уже нет грунта |
| Дорога сквозь постройку | объезд по сетке |

## 6. Порядок построения

```
1. МАГИСТРАЛИ  — две оси через центр, ищут свободные полосы
2. ПОДЪЕЗДЫ    — Г-образные улицы от каждой постройки
3. ПРОЕЗДЫ     — короткие смещения, если полоса занята
4. ФОНАРИ      — вдоль готовых дорог, без дублей
5. ПРОВЕРКА    — доступ ≤ 40 м, уклон ≤ 12 %, не по воде
```

## 7. Что даёт игроку

- дорога к постройке появляется **сразу**, без ручной прокладки;
- фонари расставлены с равным шагом, а не «как получится»;
- ночью новые улицы сразу освещены;
- если постройка стоит в неудобном месте, игра честно скажет: «нет доступа» —
  и предложит сдвинуть объект.

## 8. Ограничения текущей версии

- сетка только прямоугольная, диагональных улиц нет;
- перекрёстки не подсвечиваются отдельно (фонарь ставится по шагу);
- перекрёстки не получают зебру и светофоры;
- дороги не соединены с мостом Гуанчжоу (в той сцене своя сеть).

## 9. Что дальше

1. **Зебры и светофоры** на пересечениях улиц.
2. **Тротуары** шириной 2 м вдоль улиц.
3. **Диагональные проспекты** между дальними районами.
4. **Соединение с мостами**: съезд с моста должен продолжаться улицей.
5. **Приоритет дорог**: магистраль не должна уступать проезду.
