## Почему именно так

| Идея | Зачем поясу |
|---|---|
| **Станция в скале** | пояс перестаёт быть пустым: есть куда стыковаться и что ремонтировать |
| **Тюрьма** | источник риска: конвой, побег, погоня |
| **Научный аванпост** | повод летать в пояс за данными, а не только за рудой |
| **Крепость клана** | боевая цель: пушка, которая достаёт до трасс |
| **Стройка станции** | долгий квест с вложением ресурсов и долей прибыли |
| **Рудник с роботами** | связка с ремонтом и поломками |
| **Торговый узел** | экономика: цены, караваны, охрана |
| **Зеркало** | связка с сельским хозяйством станций (Эрос) |

## Как это встраивается в механику

1. **Карточка тела** получает список аттракционов (`body_id` → `attraction`).
2. Каждый аттракцион — точка на орбите тела: подлетел → открылась карточка.
3. Тип аттракциона определяет действия:
   - `station` — ремонт, рынок, стыковка;
   - `prison` — контракты, риск;
   - `research` — заказы на образцы;
   - `fortress` — бой, трофеи;
   - `construction` — вложение ресурсов;
   - `mining` — добыча;
   - `trade` — цены и караваны;
   - `control` — события освещения.
