# Мобы-личности: 600 жителей, которые зарабатывают и тратят

## 1. Смысл

У каждой из 6 цивилизаций — **100 мобов**. Это не декорации: каждый живёт своей
экономикой — зарабатывает по профессии, тратит на себя, а пират, удачно ограбив,
**спускает награбленное** за 1–3 тика.

```
600 мобов = 6 цивилизаций × 100
10 профессий × 60 мобов
```

## 2. Профессии

| Профессия | Доход/тик | Бережливость | Жадность | Чем живёт |
|---|---|---|---|---|
| торговец | 120 | 0,35 | 0,55 | торговля на станции |
| шахтёр | 150 | 0,55 | 0,30 | руда в поясе |
| **пират** | **180** | **0,10** | **0,85** | **грабит и спускает** |
| гонщик | 200 | 0,20 | 0,45 | заезды на Тарсисе |
| гладиатор | 170 | 0,25 | 0,50 | арены Вармира |
| игрок | 160 | 0,15 | 0,70 | казино |
| фермер | 90 | 0,60 | 0,25 | гидропоника |
| инженер | 140 | 0,50 | 0,30 | ремонт корпусов |
| медик | 130 | 0,45 | 0,25 | экипажи |
| контрабандист | 190 | 0,20 | 0,80 | груз мимо таможни |

## 3. Как моб живёт (тик 10 минут)

```
1. ЗАРАБОТОК: доход × (0,75…1,35) — случайность засеяна (seed + тик)
2. ПИРАТ: если повезло (≈28 %) — добыча ≤ 2× дохода, «гуляет» 1–3 тика
3. ТРАТА: доход × (1 − бережливость) × (0,6…1,4)
   + если есть добыча — спускает её частями за оставшиеся тика
4. ПОТОЛОК: баланс ≤ 60 000, в минус нельзя
```

## 4. Главное правило: замкнутая экономика

Мобы **не печатают кредиты игрокам и не забирают их**. Их деньги — отдельный контур.
На каждом тике проверяется тождество:

```
сумма(балансы) + сумма(потрачено) = 600 × 1000 + сумма(заработано)
```

Живая проверка: `660 905 + … = …` — тождество **OK** на каждом тике.

## 6. API

| Метод | Что отдаёт |
|---|---|
| `mob_status` | сводка: 600 мобов, по цивилизациям (балансы, заработали, потратили, сколько гуляет), 5 историй пиратов |
| `mob_list?civ=&role=` | список мобов (до 200) с балансом, настроением, последним событием |
| `mob_tick` | принудительный тик (только админ) |

## 7. Расписание

```
cron */10 * * * * php data/bin/civ-tick.php
```
Один скрипт тикает и цивилизации, и мобов.

## 8. Проверено (20/20)

```
OK 600 мобов, по 100 на цивилизацию, id уникальны
OK имена уникальны внутри цивилизации (600/600)
OK ролей 10, пиратов 60
OK доход > 0, траты > 0
OK экономика замкнута: балансы + траты = старт + доход
OK тождество держится через 13 тиков
OK пираты тратят (сумма > 0), гулянки видны
OK никто не копит сверх потолка
OK средний баланс 1 000–60 000
OK тик детерминирован
OK mob_core не читает профили игроков
```
