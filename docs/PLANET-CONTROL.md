## Три механики, которые работают в этих играх

### 1. Постановка по сетке (Minecraft)

Мир — сетка. Игрок выбирает блок, видит призрак, кликает — блок встаёт ровно в узел.
Ключевое: **призрак до подтверждения**, привязка к целым координатам, поворот.

### 2. Тайкун-петля (Roblox Tycoon)

Здание не просто стоит: оно **капает доход**. Купил дроппер → он роняет детали → лента несёт → скупщик платит → деньги на новый дроппер.
Петля: **вложение → доход → новое вложение**. Без неё город — картинка.

### 3. Колония с рабочими (MineColonies)

Здание строится не мгновенно: нужен **строитель** и **материалы**.
Дом даёт жителей, жители работают на ферме/шахте, склад хранит, доставщик носит.
Петля: **жители → работа → ресурсы → стройка → новые жители**.

## Наша схема планетарного управления

### Слои

```
1. Рельеф        — блоки земли, вода, склоны (уже есть)
2. Участки       — сетка 26×26 м у станции, привязка к целым метрам
3. Постройки     — 10 типов, призрак → клик → постановка
4. Экономика     — цена, доход в секунду, возврат 60 % при сносе
5. Логистика     — грузовик/конвейер/кран → платформа (сделано)
6. Рабочие       — жители, занятость, счастье (в разработке)
```

### Управление (как в играх)

| Действие | Клавиша / мышь | Откуда приём |
|---|---|---|
| Выбрать постройку | клик в палитре справа | Roblox Tycoon (кнопка покупки) |
| Поставить | ЛКМ по площадке | Minecraft (клик по блоку) |
| Повернуть | R | Minecraft (поворот блока) |
| Снести | ПКМ | Minecraft (ломание) |
| Вращать камеру | зажать мышь | Roblox (камера) |
| Приблизить | колесо | — |

**Призрак** показывает место: зелёный — денег хватает, красный — нет. Это ровно то, что делает Minecraft и любой строительный режим в Roblox.

### Сохранение

Город пишется в профиль игрока как строка `city:[{kind,x,z,rot}, …]` через `/api/planet/save`.
Загрузка — `/api/planet/load?world=earth`. Мир у каждого свой: Земля и Луна хранятся отдельно.

## Что дальше — по шагам

1. **Рабочие** (MineColonies): дом даёт жителей, ферма берёт 2 рабочих, шахта — 3. Без рабочих здание стоит и не приносит доход.
2. **Стройка со временем**: постановка → «строится 30 с» → готово. Как будто работает строитель.
3. **Заявки на материалы**: завод требует сталь, склад хранит, доставщик носит.
4. **Апгрейды**: уровень 1→5, каждый уровень выше и даёт больше (как Residence в MineColonies).
5. **Связь с колонией**: население планеты = сумма жителей домов; еда = фермы.
6. **Дороги**: соединение зданий дорогой ускоряет доставку.
7. **События**: пираты бьют по обороне, метеорит — по шахте.
