# Пересборка слоя сцены «Галактики»

Документ фиксирует границы, архитектуру и приёмку. Всё, что не описано здесь, менять нельзя.

## 1. Что пересобираем, а что нет

| Слой | Судьба |
|---|---|
| **Отрисовка сцены** (планеты, луны, корабли, трассы, клики) | 🔨 пересобирается в `js/scene.js` |
| Математика движения (`motion.js`) | ♻️ остаётся, вызывается через адаптеры |
| Орбиты и координаты (`worldcoords.js`) | ♻️ остаётся |
| Экономика, рынок, колонии, квесты, API | ♻️ не трогаем |
| 3D-виды (планетарный, конструктор) | ♻️ не трогаем, живут отдельно |

Причина пересборки: в `solar.js` **девять мест** пишут позиции маркеров, из-за чего один борт обновляют несколько циклов; отсюда рывки, «нос вперёд» и скорости выше света.

## 2. Архитектура нового слоя

```
scene.js
├── Scene (ядро)
│   ├── layers:        orbits | bodies | moons | routes | ships | effects
│   ├── registerBody  — планета/луна: статичный размер, источник позиции
│   ├── registerShip  — борт: источник позы (Motion.*), скорость, маршрут
│   ├── setCamera      — translate / scale / rotateX / rotateZ
│   ├── tick(nowMs)    — ОДИН RAF-цикл на всю сцену
│   └── hitTest(x,y)   — приоритет: планета > луна > корабль > фон
├── applyPose(el, pose) — ЕДИНСТВЕННЫЙ писатель позиции элемента
└── on('click'|'dblclick', cb) — роутинг событий по результату hitTest
```

### Инварианты (проверяются тестом)

1. **Один писатель.** Позиция элемента меняется только в `applyPose`. В остальном коде запрещены `style.left`, `style.top`, `style.transform` для маркеров.
2. **Один цикл.** Все обновления внутри `Scene.tick`; сторонних `setInterval` для движения нет.
3. **Физика из ядра.** Скорость берётся только из `Motion`; сцена не считает км/с и секунды.
4. **Приоритет клика.** Если точка попадает в круг планеты — событие получает планета, даже если сверху маркер корабля.
5. **Порядок слоёв.** `bodies < moons < routes < ships < effects`, планеты ниже кораблей по z, но **приоритет клика** задаётся геометрией, а не z-index.
6. **Z-index не влияет на попадание.** Клик считается по координатам тел, а не по тому, что «выше».

## 3. Кликабельность

| Объект | Действие | Приоритет |
|---|---|---|
| Планета | глобус → планетарный вид | **1** (высший) |
| Луна | планетарный вид луны | 2 |
| Корабль (торговец) | карточка борта | 3 |
| Корабль (флот) | карточка флота | 3 |
| Пустое место | снять выделение | — |

Двойной клик определяется **своим детектором** (два нажатия на один объект в 520 мс, допуск 60 px), потому что планеты движутся и нативный `dblclick` не срабатывает.

## 4. Играбельность (что нельзя сломать)

1. Часы, ускорение времени, пауза.
2. Фильтры слоёв (станции, маршруты флотов и их подгруппы).
3. Открытие глобуса, планетарного вида, карточек бортов.
4. Панели: меню, склад, управление, чат.
5. 60 FPS при 16 кораблях и 86 лунах (замер `?perf=1`).

## 5. Приёмка

| № | Проверка | Инструмент | Порог |
|---|---|---|---|
| A1 | Скорость любого борта | `tools/measure_live.js` | ≤ 0,07 c |
| A2 | Шаг за 600 с | там же | ≤ 16 px |
| A3 | Непрерывность, фазы | `tools/fleet_audit.js` | 0 разрывов |
| A4 | Приоритет клика | `tools/scene_test.js` | планета побеждает всегда |
| A5 | Один писатель позиций | статический тест | 0 нарушений |
| A6 | Кликабельность в браузере | ручная проверка владельцем | все 4 объекта |
| A7 | FPS | `?perf=1` | ≥ 50 |

Пока A1–A5 не зелёные — старый слой не отключается.

## 6. Порядок работ

1. `scene.js` — каркас, слои, `applyPose`, `hitTest`, детектор двойного клика.
2. Адаптеры: планеты/луны из `worldcoords`, флот и торговцы из `motion`.
3. Флаг `?scene=2` — новый слой рядом со старым, переключение в рантайме.
4. Тесты A1–A5.
5. Перевод по умолчанию, удаление старых апдейтеров из `solar.js`.

## 7. Риски

| Риск | Мера |
|---|---|
| Новый слой не совпадёт с визуалом | и старый, и новый рисуют из одного ядра — расхождения быть не может |
| Потеря ручных фиксов (глобус, фильтры) | фиксы переносятся в адаптеры, а не переписываются |
| Регресс для игроков | новый слой включается флагом, откат — одна строка |

## 9. Итог

Слой пересобран и включён по умолчанию; старый путь доступен как откат `?scene=1`.
Все проверяемые критерии зелёные, кроме ручного клика в браузере — его среда симулировать не может.

### Проверено в раунде 5

- новый слой включён по умолчанию, откат `?scene=1` работает;
- уникальные объекты: 8/8 позиций совпали (0.00 px);
- тесты: математика 50/50, сцена 14/14, аудит 47/47;
- стабильные `data-sid` теперь у флота, торговцев и пояса в ОБОИХ путях;
- сверка по sid: 15 общих объектов, 13 совпали точно;
- сверка ПОЛНАЯ: 42 из 42 маркеров, максимальное расхождение **0.00 px**;
- найдена и устранена причина «моргающих» правок: в шаблонах был жёстко прописан `motion.js?v=6`, из-за чего браузер держал старую версию ядра; версия поднята до 7.
