# Схема работы: локально → сервер

## Ежедневный цикл

```
1. restart-clean.bat      запуск игры локально
2. правим игру           правки в коде
3. smoke-test.ps1        проверка шести экранов
4. deploy.bat            сборка + коммит + отправка
5. Render               пересобирает сайт сам (5–10 минут)
```

## Что делает каждый файл

| Файл | Назначение |
|---|---|
| `restart-clean.bat` | чистая пересборка и запуск на `http://127.0.0.1:5080` |
| `smoke-test.ps1` | открывает 6 экранов в headless-браузере, ловит ошибки консоли |
| `deploy.bat` | тест → сборка под Linux → коммит → `git push` |
| `start-test1..3.bat` | вход под тестовыми капитанами |

## Правило

**Не отправлять на сервер, если смоук-тест не прошёл.**
`deploy.bat` специально останавливается на первом шаге при ошибке.

## Откат

Если обновление сломало игру:
```
git log --oneline            найти предыдущий коммит
git revert HEAD              отменить последний
git push                     отправить откат
```

## Администраторы

Список в `galaktika.Web/wwwroot/js/solar.js`:
```js
const ADMIN_EMAILS = ["ab@btema.ru", "admin@galaktika.ru", "owner@galaktika.ru"];
```
Свой адрес добавьте в этот список — при входе роль выдастся автоматически.
Админ видит кнопки «Админка» и «Монитор».

## Важно про профили

Профили игроков хранятся **в браузере** (localStorage), а не на сервере.
Поэтому:
- у каждого тестера свой прогресс;
- прогресс не переносится между устройствами;
- на сервере нет базы пользователей.

Для общего прогресса нужен серверный слой хранения — отдельная работа.
